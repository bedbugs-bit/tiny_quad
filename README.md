# tiny_quad

## ESP32 firmware and LLM-driven control for a small 4-legged walking robot.

See [tiny-quad/README.md](tiny-quad/README.md) for the architecture,
build/flash/test instructions, the JSON command protocol, and the Claude
companion bridge (`tiny-quad-dog/tools/claude_bridge.py`).
